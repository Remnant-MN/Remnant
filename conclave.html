ENFORCEMENT

집행부는 THE VEIL.의 명령과 규율을 직접 집행하는 조직이다. 조직 내부의 질서를 유지하고, 규칙을 위반한 자를 처리하며, ARCHON의 명령을 각 부서에 전달하고 실행한다.

AUTHORITY

AUTHORITY STRUCTURE

01

COMMAND

ARCHON의 명령을 전달하고 조직 전체에 실행한다.

02

DISCIPLINE

조직의 규칙과 내부 질서를 감시하고 유지한다.

03

EXECUTION

조직에 대한 위반과 배신에 대한 처분을 집행한다.

EXECUTIVE FUNCTIONS

OPERATIONS

01
COMMAND
ARCHON의 명령을 각 부서에 전달하고 실행 상태를 확인한다.
02
CONTROL
조직 내부의 활동과 각 부서의 규율 준수 여부를 관리한다.
03
DISCIPLINE
조직의 규칙을 위반한 조직원을 조사하고 필요한 조치를 집행한다.
04
JUDGMENT
조직에 대한 배신과 중대한 위반 사항을 판정하고 처분을 결정한다.
05
EXECUTION
결정된 명령과 처분을 직접 집행한다.
